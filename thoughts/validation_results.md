# Gap Report & Validation Status

**Date:** 2026-04-28
**Event:** Flat SIP Roof & Tapered PIR Optimization Pass
**Status:** 100% COMPLIANT

## Overview
A validation run was executed against the newly updated roof schedule, which reduces the roof SIP from 175mm to 150mm, laid completely flat, utilizing Tapered PIR bonded to the top to create the 1:60 fall.

## Test Suite Results

*   **Test 002 (Roof Structure & Height Limit):** PASS. 
    *   *PD Limit Checked:* The absolute highest point of the building is exactly 2500mm (150mm exposed splash + 2096mm wall + 150mm SIP + 87mm PIR + 1.5mm EPDM + 0.5mm VCL + 15mm Fermacell). 
    *   *Structural Span:* A 150mm SIP can still structurally span the 3.43m clear width safely within L/240 deflection limits, provided it is joined with insulated splines.
*   **Test 003 (Wall & Vapour):** PASS. The vapor profile is the gold-standard "Warm Roof". The VCL protects the inside, the PIR is closed-cell insulation preventing dew-point condensation within the timber, and the EPDM provides the outer weather seal.
*   **Test 05 (Flush Threshold Moisture):** PASS. The 1:60 roof fall is perfectly maintained by the 30mm-to-87mm tapered PIR blocks.

**Conclusion:** The Master Plan and Workplan are updated. The internal geometry is significantly improved (flat ceiling) and thermal performance is enhanced.

# Architectural Test Suite

Welcome to the `/tests` directory for the Garden Room Project. 

Since this is an architectural planning repository (not a software coding project), our "tests" are strict verification checklists and physics-based validation protocols. They ensure that our generated Standard Operating Procedures (SOPs), Master Plans, and Workplans are structurally sound, legally compliant, and logistically possible.

## How to Run These Tests

As an AI Agent (e.g., `@architect`, `@foreman`, or `@general`), you must proactively "run" these tests before finalizing any major update to the `MASTER_PLAN_*.md` or `WORKPLAN_*.md` files.

To "run" a test:
1. **Read the Test File:** Open the relevant `.md` test file in this directory.
2. **Execute the Checklist:** Compare the rules, physics constraints, and formatting requirements against your generated Master Plan or Workplan.
3. **Assert Pass/Fail:** If your plan violates a "Failure State," you must immediately halt, correct the plan to satisfy the physics/logistics of the test, and document the fix in `/thoughts/site_journal.md`.

## The Test Suite

*   `01_thermal_red_line.md` - Validates the continuity of the Passivhaus thermal envelope.
*   `02_weather_tight_timeline.md` - Validates the sequencing of moisture defense (e.g., immediate Tyvek wrapping).
*   `03_structural_sequence.md` - Validates the chronology of the build against gravity, curing times, and manual labor limits.
*   `04_boundary_fire_safety.md` - Validates compliance with Approved Document B (<1m boundary fire rules) and ATEX dust extraction safety.
*   `05_flush_threshold_moisture.md` - Validates the physical geometry of the level threshold against capillary wicking and coastal flooding.
*   `06_sop_fidelity_linter.md` - Validates the formatting of Markdown tables, metric units, and the presence of material quantities.

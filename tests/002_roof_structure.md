# Test 002: Roof Structure

**Requirement:** The roof must utilize a "Warm Roof" methodology.
**Rationale:** Eliminates roof condensation risks while prioritizing thermal performance.
**Constraint:** All insulation must be entirely *on top* of the timber joists. The overall building height must remain strictly under the 2.5m Permitted Development limit.
**Validation:** The master plan must clearly define the roof build-up with insulation above the joists and explicitly state the total external height is ≤ 2.5m. If using heavy SIP panels, the plan must specify splitting 1200mm panels into 600mm narrow-format ones or hiring a material lift.
